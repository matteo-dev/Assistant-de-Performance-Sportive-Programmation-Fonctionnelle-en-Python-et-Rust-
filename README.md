# Assistant-de-Performance-Sportive-Programmation-Fonctionnelle-en-Python-et-Rust-
Assistant de pilotage de la performance sportive (1RM, ACWR, EWMA) implémenté selon les principes stricts de la programmation fonctionnelle (zéro mutabilité avec @dataclass(frozen=True), fonctions pures, lazy iterators et transparence référentielle).
